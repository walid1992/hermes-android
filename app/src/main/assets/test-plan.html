1. HermesContext — Core Runtime

Context Lifecycle

Create and close context
HermesContext should create without crash, close() releases native memory
HermesContext ctx = new HermesContext(); ctx.close(); assert ctx.isClosed();
eval() basic expression
Evaluate simple expression returns correct string
String r = ctx.eval("1 + 2 + 3");
Expected: "6"
eval() string result
Last expression value returned as string
String r = ctx.eval("'hello' + ' ' + 'world'");
Expected: "hello world"
evalInt() / evalDouble() / evalBoolean()
Typed eval returns correct Java primitive
int i = ctx.evalInt("10 * 5"); // 50 double d = ctx.evalDouble("22/7"); // 3.14... boolean b = ctx.evalBoolean("1>0"); // true
execute() no return
execute() runs script without returning, no crash
ctx.execute("var x = 42;"); String r = ctx.eval("x"); // "42"
JS Error handling
Syntax/runtime errors throw RuntimeException on Java side
try { ctx.eval("@#$invalid"); } catch (RuntimeException e) { /* JSError */ }

2. JSObject — Set Property

Create and Set Properties from Java

setProperty — String
JSObject obj = ctx.createNewJSObject(); obj.setProperty("name", "Hermes Wrapper"); global.setProperty("obj", obj); ctx.eval("obj.name"); // "Hermes Wrapper"
setProperty — int / double / boolean
obj.setProperty("year", 2025); obj.setProperty("version", 1.1); obj.setProperty("active", true);
obj.year=2025, obj.version=1.1, obj.active=true
setProperty — nested JSObject
JSObject child = ctx.createNewJSObject(); child.setProperty("x", 10); obj.setProperty("nested", child); ctx.eval("obj.nested.x"); // "10"
setProperty — JSCallFunction
Inject a Java lambda as JS function property
obj.setProperty("greet", (JSCallFunction) args -> "Hello " + args[0]); ctx.eval("obj.greet('World')"); // "Hello World"

3. JSObject — Get Property

Read JS Properties from Java

getString / getInteger / getDouble / getBoolean
ctx.execute("var p = {name:'test', age:30, score:9.5, ok:true}"); JSObject p = global.getJSObject("p"); p.getString("name"); // "test" p.getInteger("age"); // 30 p.getDouble("score"); // 9.5 p.getBoolean("ok"); // true
getJSObject — nested object
ctx.execute("var o = {child: {val: 42}}"); JSObject child = global.getJSObject("o").getJSObject("child"); child.getInteger("val"); // 42
getJSFunction — call JS function from Java
ctx.execute("var math = { add: function(a,b){return a+b;} }"); JSFunction fn = global.getJSObject("math").getJSFunction("add"); Object result = fn.call(3, 4); // 7.0 (Double)
hasProperty
ctx.execute("var h = {exists: 1}"); JSObject h = global.getJSObject("h"); h.hasProperty("exists"); // true h.hasProperty("missing"); // false

4. JSArray

Array Operations

createNewJSArray + set elements
JSArray arr = ctx.createNewJSArray(); arr.set(0, "a"); arr.set(1, "b"); arr.set(2, "c"); global.setProperty("arr", arr); ctx.eval("arr.join('-')"); // "a-b-c"
Read array from JS — length() + get()
ctx.execute("var nums = [10, 20, 30]"); JSArray nums = global.getJSArray("nums"); nums.length(); // 3 nums.get(0); // 10.0 (Double) nums.get(2); // 30.0
Mixed type array
ctx.execute("var mixed = [1, 'hello', true, null, {x:1}]"); // get(0) → Double, get(1) → String, get(2) → Boolean, get(3) → null, get(4) → JSObject

5. JSFunction — Call from Java

Calling JS Functions

call() with primitive args
ctx.execute("function add(a,b) { return a+b; }"); JSFunction fn = global.getJSFunction("add"); Object r = fn.call(10, 20); // 30.0
call() returns string
ctx.execute("function greet(n) { return 'Hi ' + n; }"); JSFunction fn = global.getJSFunction("greet"); fn.call("Bob"); // "Hi Bob" (String)
callVoid() — no return
ctx.execute("var log = ''; function append(s) { log += s; }"); JSFunction fn = global.getJSFunction("append"); fn.callVoid("test"); ctx.eval("log"); // "test"

6. JSCallFunction — Java Callback

Java Functions Callable from JS

Basic callback
global.setProperty("javaAdd", (JSCallFunction) args -> { return ((Number)args[0]).doubleValue() + ((Number)args[1]).doubleValue(); }); ctx.eval("javaAdd(3, 4)"); // "7"
Callback returning function (higher-order)
global.setProperty("multiplier", (JSCallFunction) args -> { double f = ((Number)args[0]).doubleValue(); return (JSCallFunction) inner -> ((Number)inner[0]).doubleValue() * f; }); ctx.eval("multiplier(5)(6)"); // "30"
Callback with string args
global.setProperty("upper", (JSCallFunction) args -> ((String)args[0]).toUpperCase()); ctx.eval("upper('hello')"); // "HELLO"

7. Object Lifecycle & Release

Memory Management

release() prevents use-after-free
After release(), calling methods throws IllegalStateException
JSObject obj = ctx.createNewJSObject(); obj.release(); try { obj.getString("x"); } catch (IllegalStateException e) { /* expected */ }
